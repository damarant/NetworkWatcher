🛡️ NetworkWatcher v1.0.0

Configuration

📶 Wi-Fi Setup
Connect the device to your home network. Scan available networks and test the connection before saving.
📡 Network Scan
Run an ARP scan of your home network to detect all connected devices.
📋 MAC Lists
View and manage whitelist, blacklist and unknown devices. Includes vendor and IP for each device.
⚙️ Settings
Change password, scan interval, configure Telegram and Webhook, run backup/restore and factory reset.
📜 System Log
View the latest WARNING and ERROR messages. Useful for diagnostics without a serial connection.
