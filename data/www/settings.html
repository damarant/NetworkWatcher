🔗 Webhook Notifications

Send notifications via HTTP POST to an external service not configured

Compatible with ntfy.sh, Discord, Slack, IFTTT, Home Assistant, Gotify, custom servers. Must start with http:// or https://.

If set, it is sent as header Authorization: Bearer XXX. Use it for Slack, Gotify, Home Assistant, ntfy with token.

The test uses the URL and token entered above, without saving them first. If you receive the notification on the service, they are correct: you can save them.

💾 Backup and Restore

Export or import MAC lists and scan settings. Does not include WiFi credentials, admin password, Telegram, Webhook.

Download a .json file with whitelist, blacklist and unknown. Keep it to restore the lists after a full flash.

⚠️ Importing replaces the current lists with those from the file. This operation is not reversible. The file is loaded as-is: any manual modifications are at your own risk.

⚠️ Factory Reset

Deletes EVERYTHING: Wi-Fi credentials, MAC lists, settings, admin password, Telegram, Webhook. The device will return to the initial state.
