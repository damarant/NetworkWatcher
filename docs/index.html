🛡️ NetworkWatcher

v1.0.0

Install NetworkWatcher on your ESP32-S2 mini (WEMOS) directly from your browser. No drivers, no Python, no esptool required.

Before you start:
  1. Connect the board to your PC via USB
  2. Hold BOOT, press and release RST, then release BOOT
  3. Click Install below and select the serial port
⚠️ Full flash: this will overwrite the storage partition and erase your MAC lists. Back them up from the web UI first if needed.

Requires Chrome, Edge or Opera (desktop).
Web Serial API is not supported on Firefox, Safari or mobile browsers.
